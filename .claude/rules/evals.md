# Evals

- Datasets come from `make seed` (seed `20261022`, `*.v1`); dev/test split fixed; never tune on test; never edit an existing `evals/datasets/*.test.jsonl` (add a new version).
- The runner emits `evalgate.report.v1`; `evals/REPORT.md` is generated by script from the latest run and states mode (offline/real), Exo commit and dataset hashes.
- Thresholds are in BUILD.md §11. A miss is fixed in code or recorded in `docs/KNOWN_LIMITATIONS.md`, never by relaxing the threshold.
- Live runs are maintainer-only (`make eval-live`, guarded); the report says "live evals were not run" unless they were.
