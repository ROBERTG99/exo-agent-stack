# Documentation

- English. Every number in a doc or the README cites the command or report that produced it; never invent metrics, scores or screenshots.
- Architectural choices get an ADR in `docs/adr/` (`new-adr` skill) and a dated entry in `docs/DECISIONS.md`.
- Keep `docs/KNOWN_LIMITATIONS.md` honest: what is not done and why. State Mode B status in the README.
- markdownlint must be clean; fenced code blocks carry a language.
