# Add an eval case

1. Cases are generated by `data/generator` (seed `20261022`). Change the generator, then run `make seed`; never hand-edit generated files.
2. Existing `evals/datasets/*.test.jsonl` are immutable: add a new version (`*.v2`) and update the suite config and hashes.
3. Add a unit test for the generator change, then run the suite (`make eval-<suite>`) and regenerate `evals/REPORT.md`.
4. Gold labels come from the generator; list any case needing maintainer review under "Needs the maintainer" in `PROGRESS.md`.
